# 이전 이름 호환

이 스킬은 별도 개발 엔진이 아니다. 설치된 dive-builder/SKILL.md와 dive-webapp/SKILL.md를 찾아 읽는다.
표준 묶음은 형제 폴더에 두 스킬을 함께 설치한다. 없으면 묶음 설치를 안내하고 전체 기능이 있다고 주장하지 않는다.
새 프로젝트를 이 이름으로 명시 호출했다면 예전 용도인 웹앱 모드를 제안한다. 기존 프로젝트는 PLAN의 모드와 합의한 목표를 따른다.
인터뷰·진행 기록을 중복 생성하지 않는다. 기존 PROJECT/PLAN/사용자 변경을 보존한다.
구 CLI 경로의 init만 기본 webapp으로 연결한다. status/check는 공통 도우미를 사용한다.
